# RS ASSISTANCE 🤖

Android-first personal assistant starter project.

## Included
- Java Android application
- Bengali speech input using Android SpeechRecognizer
- Spoken responses using Android TextToSpeech
- GitHub Actions workflow for debug APK builds

## Important
This is the first runnable starter, not the complete planned assistant. Wake-word standby, AI brain, custom voice cloning, long-term memory, camera vision, and smart-home control are future modules and are not implemented yet.
